# AARPG

An action Adventure RPG built with Godot 4, py4godot, and Esper ECS.

## Key Features

- 🎯 **Python-driven ECS** - An entity component system that works at the base
C++ layer
- 🚀 **Player movement prototype** - Can be ported and used for other games
- 🔧 **Flexible Systems** - Re-usability is key!
- 📦 **Editor Support** - Built using nevim/lazyvim

## Requirements

Godot 4.x (tested with 4.6.2)

## Installation

Open the project in Godot 4. Add py4godot from the asset store. Relaunch Godot.
Run the game.
